# NPAi Project Hub

Interactive management dashboard mockup for eight design and construction workflows.

Live dashboard: https://netzpj-max.github.io/NPAi-Project-Hub/
Reports workspace: https://netzpj-max.github.io/NPAi-Project-Hub/#reports

## Scope

Thai interface with a clean light theme. Includes project/task management, AI brief templates, reference-file metadata, CAD/model mock views, editable sample BOQ, manual revision review, a 4D concept slider, report templates and handover simulation.

All project data, quantities, prices, review states, plans and generated reports are demo data. This mockup does not call AI, read CAD/BIM geometry, upload reference-file contents, or connect to production services. State is stored in this browser's localStorage, not a shared database. Local browser state is not access control or proof of approved construction work.

The repository contains only the static mockup and its intended image/logo/font assets. No NPAiRENDER application backend, account credentials or original project documents are included.
